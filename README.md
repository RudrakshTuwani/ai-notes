# AI Notes

Compact notes and cheatsheets for understanding modern language models.

The MkDocs site is published at <https://rudrakshtuwani.github.io/ai-notes/>.

## Local preview

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```

Every push to `main` builds and deploys the site through GitHub Pages.
