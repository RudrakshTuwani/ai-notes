# AI Notes

This repo contains cheatsheet-style notes for understanding modern language
models, from architecture to training and systems. Optimize for quick review
and durable understanding.

When writing or updating a topic page:
- Cover motivation (what problem it solves), mathematical definition, and
  intuition (why it works).
- Define symbols, tensor shapes, and assumptions alongside equations.
  Follow the existing tokens-as-columns convention.
- Keep writing skimmable: descriptive headings, short paragraphs, bullets,
  and selective bolding for key takeaways.
- Use a small worked example or diagram when it makes an abstract idea concrete.
  Put longer derivations in collapsible sections.
- Include easy questions that check understanding and medium questions that
  require application or reasoning. Put answers in collapsible sections.
- Link to primary sources for definitions and further reading.
